Common pitfalls (short)

- macOS + PyMultiNest: system libmultinest may be missing — prefer installing `multinest` from `conda-forge` and `pymultinest` there.
- xarray interpolation: convert numpy scalar coords to Python scalars before calling `DataArray.interp(**kwargs)` to avoid TypeError.
- MultiNest long basenames: run in the output dir and use short basenames (e.g. `RAW_`).
