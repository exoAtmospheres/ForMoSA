Deploying ForMoSA On A Cluster Using MPI
========================================

The repository currently documents the installation prerequisites for
``pymultinest``, ``MultiNest``, and ``mpi4py``. That is the verified foundation
for cluster-oriented deployments in the current documentation tree.

What Is Documented Today
------------------------

* installation steps for ``PyMultiNest`` and ``MultiNest``;
* optional MPI-related settings in ``ConfigPyMultiNest`` such as ``init_MPI``
  and ``use_MPI``.
