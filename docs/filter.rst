Photometry Filters
==================

The :class:`~ForMoSA.filter.filter.PhotometryFilter` class interfaces with the
`Spanish Virtual Observatory Filter Profile Service <https://svo2.cab.inta-csic.es/theory/fps/>`_
to retrieve and cache filter transmission curves.
